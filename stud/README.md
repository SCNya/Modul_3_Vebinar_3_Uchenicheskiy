# Учебная задача «Персональные рекомендации книг»

Комплект подготовлен для третьего модуля ML-буткемпа.

## Размер данных

- читателей: 700;
- книг: 80;
- исторических взаимодействий: 5600;
- кандидатов для каждого читателя: 20;
- правильных книг в целевом периоде: 5;
- train: 400 читателей;
- valid: 100 читателей;
- test: 200 читателей.

## Файлы

- `users.csv` — профили читателей;
- `books.csv` — каталог книг;
- `interactions.jsonl` — история за периоды 1 и 2;
- `candidates.csv` — 20 кандидатов для каждого читателя, с колонкой `split`;
- `train_choices.jsonl` — фактический выбор train-читателей в периоде 3;
- `valid_solution.csv` — правильные ответы для локальной проверки;
- `sample_submission.csv` — пример файла для test;
- `metric.py` — проверка формата и расчёт NDCG@5;
- `data_dictionary.csv` — описание столбцов.

## Логика разбиения

У всех читателей есть история за два периода. Читатели разделены на непересекающиеся группы train, valid и test. Для каждого читателя подготовлено 20 книг-кандидатов на период 3.

- Для train фактические пять выборов открыты в `train_choices.jsonl`.
- Для valid правильные пять книг открыты в `valid_solution.csv` и используются только для локальной метрики.
- Для test правильные ответы скрыты; участник формирует `submission.csv` по образцу.

## Проверка решения

```python
from metric import ndcg_at_5

score = ndcg_at_5(
    "valid_solution.csv",
    "my_valid_submission.csv",
    "candidates.csv"
)
print(score)
```

Перед расчётом функция проверяет, что для каждого читателя указано ровно пять разных книг и все они входят в его список кандидатов.


## Отправка на платформу

Для тестовой части нужно создать `submission.csv` по образцу `sample_submission.csv`. Платформа проверяет файл на скрытых ответах и показывает публичное значение NDCG@5. Итоговый лидерборд строится по приватной части тестовых данных.

Подробные ограничения описаны в `ТРЕБОВАНИЯ_К_SUBMISSION.md`.
