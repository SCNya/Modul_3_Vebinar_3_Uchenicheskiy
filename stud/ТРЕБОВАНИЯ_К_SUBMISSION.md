# Формат файла отправки

Участник загружает на платформу файл `submission.csv` в кодировке UTF-8.

Требования:

- в файле должны быть ровно две колонки: `reader_id` и `recommendations`;
- заголовок обязателен;
- одна строка соответствует одному читателю из тестовой части;
- каждый `reader_id` должен встречаться ровно один раз;
- в `recommendations` должны находиться ровно пять идентификаторов книг;
- идентификаторы разделяются одним или несколькими пробелами;
- книги не должны повторяться;
- каждая книга должна входить в список кандидатов этого читателя;
- порядок книг влияет на итоговую метрику;
- дополнительные колонки и дополнительные читатели запрещены.

Пример:

```csv
reader_id,recommendations
r_00004,b_031 b_003 b_075 b_042 b_072
```

При сохранении через pandas индекс добавлять не нужно:

```python
submission.to_csv("submission.csv", index=False)
```
